# API Documentation Fundamentals

Effective API documentation helps developers understand how an API works and how to use it successfully.

This section demonstrates the fundamental concepts that a technical writer needs to understand when creating API documentation.

It covers the terminology, concepts, and technical building blocks commonly encountered when documenting APIs.

> For a structured, step-by-step learning experience, see [**Module 09 — API Documentation**](/docs/08-API-Documentation/) in the Learning Hub.

## API documentation at a glance

API documentation typically needs to answer five fundamental questions:

1. What does the API do?
2. How do I authenticate?
3. What request do I need to send?
4. What response should I expect?
5. What should I do if something goes wrong?

Good documentation provides these answers clearly, consistently, and in the context of the developer's workflow.

## What technical writers need to understand

Technical writers working with APIs should be comfortable with concepts such as:

- APIs and endpoints
- HTTP methods and status codes
- Requests and responses
- Headers and parameters
- JSON
- Authentication
- Error handling
- API versioning
- OpenAPI specifications
