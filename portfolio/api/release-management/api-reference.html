Release Management API (1.0.0)

Download OpenAPI specification:

License: Portfolio Project

A fictional REST API for managing software releases, tracking changes and work items, coordinating approvals, and preparing release notes.

This API is a portfolio project designed to demonstrate realistic API design and developer documentation practices.

Releases

Manage software releases.

List releases

Returns a paginated list of software releases.

Authorizations:
bearerAuth
query Parameters
status
string
Enum: "draft" "in_progress" "ready_for_approval" "approved" "released" "cancelled"
Example: status=released

Filter releases by lifecycle status.

page
integer >= 1
Default: 1
Example: page=1

Page number to return.

pageSize
integer [ 1 .. 100 ]
Default: 20
Example: pageSize=20

Number of releases to return per page.

Responses

Fictional API server for portfolio demonstration

https://api.release-management.test/v1/releases

Create a release

Creates a new software release.

Authorizations:
bearerAuth
Request Body schema: application/json
required

Release information required to create a new release.

version
required
string

Release version identifier.

name
required
string

Human-readable name of the release.

status
string
Default: "draft"
Enum: "draft" "in_progress"

Initial lifecycle status of the release.

targetDate
required
string <date>

Planned release date.

description
string

Summary of the release.

page
integer >= 1
Default: 1
Example: page=1

pageSize

List work items

Returns a list of work items, optionally filtered by release and status.

Authorizations:
bearerAuth
query Parameters
releaseId
string
Example: releaseId=rel_2026_08

Filter work items associated with a specific release.

status
string
Enum: "open" "in_progress" "completed" "cancelled"
Example: status=completed

Filter work items by their current status.

priority
string
Enum: "low" "medium" "high" "critical"
Example: priority=high

Filter work items by priority.

page
integer >= 1
Default: 1
Example: page=1

Page number to return.

pageSize
integer [ 1 .. 100 ]
Default: 20
Example: pageSize=20

Number of work items to return per page.
