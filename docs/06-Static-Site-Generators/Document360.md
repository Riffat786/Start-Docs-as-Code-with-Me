# Document360

**Type:** Hosted knowledge base platform (SaaS)

**Best for:** Support and product teams that need a hosted, searchable help center with analytics

**Last verified:** Check the official Document360 site for current features and pricing.

---

## What It Is

Document360 is a cloud-based knowledge base platform. Authors write content in a web editor. The platform hosts a searchable portal for readers.

---

## Who It Suits

- Support and customer-success teams
- Product teams that need a branded help center
- Organizations that want analytics and user roles without managing servers

---

## Strengths

- Web editor, so no local setup is needed
- Hosted portal with search and reader analytics
- Support for versions and multiple languages
- Roles and review steps for team collaboration

---

## Limitations

- Content is stored in the platform, not in your Git repository
- Less control over layout, build process, and code
- Subscription cost grows with team size and features

---

## Docs-as-Code Fit

Document360 is a content management platform. It is not a Docs-as-Code tool. Content does not live in Git, so pull requests, code review, and CI/CD checks do not apply directly. Some teams use an export or sync step to move content into a repository. Check the official documentation for current options.

---

## When to Choose It

Choose Document360 when non-technical writers and support teams need to edit content directly. Choose it when analytics and a hosted help center matter more than version control.

---

## Verdict

Strong for hosted help centers. Weak for Docs-as-Code workflows that depend on Git.
