# Docusaurus

**Type:** Open-source static site generator (React)

**Best for:** Documentation sites that need versioning, a custom homepage, React components, and a polished default design

**Last verified:** Not yet. Check the official Docusaurus site for current features and version details before publishing.

---

## What It Is

Docusaurus builds a documentation website from Markdown and MDX files. It is built on React, so you can add custom pages and interactive components. It includes search, versioned docs, sidebars, a navbar, and a blog. This course uses Docusaurus for the site you are reading now.

---

## Who It Suits

- Teams that document software products and want versioned docs
- Projects that need custom pages, such as a landing page or a portfolio
- Developers and writers who are comfortable with React and npm

---

## Strengths

- Built-in versioning of documentation
- Custom pages and React components through MDX
- Configurable sidebars, navbar, and theme, with dark mode support
- Works well with Git, so pull requests, code review, and CI/CD apply directly
- Free to host on GitHub Pages, Netlify, or Vercel

---

## Limitations

- Requires Node.js and npm, so the setup is heavier than a Markdown-only tool
- Customizing the theme or components needs some React and CSS knowledge
- Upgrades between major versions can need configuration changes

---

## Docs-as-Code Fit

Docusaurus is a strong Docs-as-Code fit. Content lives in Git as Markdown and MDX. Pull requests, code review, preview builds, and automated deployment work the same way they do for code. The site is generated as static files, so hosting is simple.

---

## When to Choose It

Choose Docusaurus when you need versioned docs, a custom homepage, or React components, and your team can manage a Node.js project. Choose MkDocs for a simpler, Markdown-only setup. Choose a hosted platform such as GitBook or Document360 when non-technical writers must edit content directly.

---

## Verdict

Flexible and well suited to Docs-as-Code. More setup and React knowledge than simpler generators need.
