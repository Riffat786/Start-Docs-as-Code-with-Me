# Certifications

Certifications show employers that you have a defined set of skills. They do not replace experience, a portfolio, or a strong writing sample. This page lists certifications relevant to the course, and what to check on each official page.

**Last checked:** November 2026. Requirements, costs, and renewal rules change. Always confirm on the official page before you plan a budget or a date.

---

## GitHub Foundations (Microsoft)

| Item | Detail |
|---|---|
| Exam code | GH-900 |
| Level | Beginner |
| Topics | Git and GitHub basics, working with repositories, collaboration, modern development practices, project management, privacy and security, and the GitHub community |
| Duration | 100 minutes, according to the official page |
| Renewal | The official page states that no renewal is required. |
| Booking | Through Pearson VUE. The exam is proctored. |
| Practice | A practice assessment is available on the official page |
| Cost | Varies by country. Check the official page for the price in your region. |

**Why it matters for technical writers:** Docs-as-Code depends on Git and GitHub. This certification confirms that you understand the platform your documentation lives on.

**Official page:** [GitHub Foundations on Microsoft Learn](https://learn.microsoft.com/en-us/credentials/certifications/github-foundations)

## Certified Professional Technical Communicator (CPTC), STC

The Society for Technical Communication (STC) offers the CPTC. Its requirements have changed over time, and sources do not agree on the current version.

:::warning

When this page was last checked, the STC website showed a maintenance notice ("We're Currently Under Update") instead of its certification pages. The CPTC requirements could not be confirmed. Check the STC site directly before you plan an application, and ask STC for the current rules if the site is still down.

:::

Confirm the current eligibility, exam, and renewal rules on the STC website.

**What to check:**

- Whether you need experience, membership, or both
- The exam format, pass mark, and cost
- The renewal cycle, and how continuing education points are earned

**Official site:** [Society for Technical Communication](https://www.stc.org/)

## Google Technical Writing Professional Certificate (Coursera)

Google offers a technical writing certificate on Coursera, aimed at people who are starting in the field. Check the course count, the expected weekly time, the skills taught, and the price on the Coursera program page. These details change, so do not rely on figures from third-party articles.

**Search for:** "Google Technical Writing Professional Certificate" on Coursera.

## How to choose a certification

| Question | Why it matters |
|---|---|
| Do I need a credential, or a portfolio? | A portfolio often matters more for technical writing roles |
| Does the target role use GitHub? | A GitHub credential helps if the role works in Git every day |
| Do I meet the eligibility rules today? | Some credentials require years of experience |
| Does the credential renew, and at what cost? | Renewal is a recurring cost and effort |

:::note

Use this course's portfolio as evidence of your skills. A certification and a published, well-reviewed documentation project together make a stronger case than either one alone.

:::
