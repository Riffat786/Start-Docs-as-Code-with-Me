# Appendix

This appendix holds reference material that supports the course. Use it while you work and while you plan your career. The modules teach the skills. The appendix helps you find the tools, the reading, and the credentials that come next.

## How to keep this appendix accurate

Tools and rules change. Before you rely on a detail in this appendix, check the official source.

- Each page shows a "Last checked" date.
- Prices, durations, and renewal rules change often. Confirm them on the official page.
- If you find an outdated detail, report it through a pull request, with the official source as evidence.
