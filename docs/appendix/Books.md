# Books

This page lists books that help technical writers learn the craft and the tools covered in this course. It is for reference. Editions, prices, and availability change, so check the publisher's page before you buy.

**Last checked:** November 2026

---

## Docs-as-Code and documentation for developers

| Book | Author | Why read it | Note |
|---|---|---|---|
| Docs Like Code | Anne Gentle | An early and practical introduction to treating documentation like software | First published in 2017. Use it for principles, and check current tools against the official docs. |
| Docs for Developers: An Engineer's Field Guide to Technical Writing | Jared Bhatti and co-authors | Explains how to plan, write, and maintain documentation for engineering teams | Written for engineers who write documentation, with useful guidance for writers too. |
| Technical Writing for Software Developers | Packt | Covers documentation types, writing style, and version-controlled documentation tools | Published by Packt in 2024. Check the edition before you buy. |

## Technical writing fundamentals

| Book | Author | Why read it | Note |
|---|---|---|---|
| Technical Communication Today | Richard Johnson-Sheehan | A textbook that covers audience, document design, and the writing process | Used in many technical communication courses. |
| Developing Quality Technical Information | Gretchen Hargis and co-authors | A handbook on planning, writing, and reviewing technical information, from IBM | Focuses on quality and review, which complements the review lessons in this course. |

## How to choose

- Start with one fundamentals book, and one book on docs-as-code.
- Read a book in the same week that you practice its ideas on a real page.
- Check whether a book's tools are still current. Principles last longer than tool steps.
