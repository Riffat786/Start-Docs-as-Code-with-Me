# Module 12 – AI for Technical Writers

Discover how AI enhances every stage of the documentation lifecycle—from planning and content creation to review, localization, and publishing. This module focuses on practical AI workflows specifically for Technical Writers.

---

## What You'll Learn

By the end of this module, you will be able to:

- Use AI throughout the documentation lifecycle.
- Generate technical content using AI.
- Automate release notes.
- Improve documentation quality.
- Enhance localization workflows.
- Review AI-generated content effectively.

---

## Topics Covered

- AI-Assisted Writing
- AI for API Documentation
- AI Release Notes
- Content Governance
- Localization with AI
- Documentation Review
- Quality Assurance
- Human-in-the-Loop Review
